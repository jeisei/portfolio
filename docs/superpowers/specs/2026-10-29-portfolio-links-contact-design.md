# Portfolio links and contact form design

## Intent

Обновить существующее статическое портфолио без изменения его дизайна: направить Telegram-ссылки на `https://t.me/jeiseidev`, заменить ссылки четырёх карточек проектов, убрать CV с сайта, подключить GitHub и настроить отправку контактной формы на `maximus17power@gmail.com`.

## Goals

- Все ссылки Telegram ведут на аккаунт `jeiseidev`.
- Карточки работ ведут на три указанных проекта; четвёртая карточка остаётся визуально без изменений, но получает безопасную ссылку-заглушку только если отдельная ссылка не указана.
- Удалить обе кнопки CV и файл `assets/cv/max-shemchuk-cv.pdf`.
- Ссылка GitHub ведёт на `https://github.com/jeisei`.
- Форма отправляет имя, компанию, email, телефон и сообщение через FormSubmit на `maximus17power@gmail.com`.
- Не менять HTML-структуру, CSS, изображения и визуальное оформление за пределами необходимого.
- Создать публичный GitHub-репозиторий и загрузить проверенный проект.

## Non-goals and constraints

- Не переделывать дизайн, тексты, адаптивность или анимации.
- Не добавлять сервер и зависимости.
- FormSubmit может запросить подтверждение адреса после первой отправки; это ограничение внешнего сервиса.

## Approaches

1. FormSubmit — выбранный вариант: минимально подходит статическому сайту, не требует backend-кода.
2. Formspree — требует отдельной регистрации и endpoint, поэтому добавляет лишнюю настройку.
3. `mailto:` — открывает почтовый клиент посетителя и не гарантирует доставку, поэтому не подходит.

## Implementation outline

- Изменить только необходимые `href` и атрибуты формы в `index.html`.
- Удалить CV-ссылки из hero/about и сам PDF-файл.
- Добавить валидационные/служебные поля FormSubmit без изменения стилей формы.
- Инициализировать Git, проверить отсутствие CV и старых ссылок, выполнить статические проверки и проверить страницу в браузере.
- Создать публичный репозиторий через GitHub и отправить туда проверенный проект.

## Open implementation call

Для четвёртой карточки отдельный URL не задан; сохраню её дизайн и оставлю ссылку `#`, чтобы не придумывать адрес и не направлять посетителей на неверный сайт.
